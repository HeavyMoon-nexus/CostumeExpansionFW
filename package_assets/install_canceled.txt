Costume Expansion FW - nothing was installed
============================================

You told the installer you still have box tokens equipped, so it stopped. This
folder holds this file and nothing else: no esp, no DLL, nothing that runs.

One thing to check first
------------------------

A FOMOD installer cannot refuse to install. The most it can do is install
nothing useful, which is what this is. So if your mod manager asked whether to
REPLACE an existing Costume Expansion FW and you said yes, it replaced your
working install with this folder, and you need to reinstall the version you
were on before going back in game. If you installed this as a new, separate
mod - which is what you want here - your existing install is untouched and you
can just disable or delete this one.

Why it asks
-----------

Up to 1.6.2, a costume's enchantments were handed to you through a spell that
only existed while the game was running. Quit the game and that spell is gone,
but the bonus it applied is written into your save, and there is nothing left
for Skyrim to take it back off with. It stays on your character, and doing it
again adds to it.

1.6.3 replaces that mechanism so it cannot happen again. What it cannot do is
clean up a bonus that is already stuck, because it has no way to tell its own
leftovers from a bonus another mod applied on purpose.

What to do
----------

Go back to the version you have now and:

1. Take off every box token.
2. Check your stats came back. Before you take the tokens off, run

       cef av base

   and after, run

       cef av diff

   That lists what CHANGED when the tokens came off, which is the part you
   care about. "cef av" on its own lists every actor value that anything is
   modifying - other mods, perks, diseases, blessings - and cannot tell you
   which of them is CEF's.
3. Save.
4. Run this installer again and pick the first option.

If a bonus is still there after the tokens are off, it is already stuck.
1.6.3 will not remove it. To take it off by hand:

       player.getavinfo health
       player.modav health -250

using whatever number the first command shows as the modifier. Do this before
you update, while you still know which bonus came from where. Afterwards you
would be guessing.

If you changed your mind
------------------------

If you meant to install and picked the wrong option, just run the installer
again. Nothing here needs undoing.
